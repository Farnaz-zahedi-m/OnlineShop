- OnlineShop

An e-commerce web application built with ASP.NET Core MVC, Entity Framework Core, and Clean Architecture.

 --Technologies

* ASP.NET Core 9 MVC
* C#
* Entity Framework Core 9
* SQL Server
* Clean Architecture
* Repository Pattern
* Service Layer
* AutoMapper
* ASP.NET Core Identity PasswordHasher
* Bootstrap
* JavaScript / jQuery
* HTML / CSS
* Docker
* Docker Compose
* Git & GitHub

-- Features

* User registration and login
* Password hashing
* User management
* Role management
* Admin area
* Product group management
* Product management
* Product image and gallery management
* Product filtering by group
* Product details
* Shopping cart
* Add/remove products from cart
* Product pagination
* Responsive UI with Bootstrap
* Dockerized application environment
* Docker Compose configuration

-- Architecture

The project follows a Clean Architecture structure:

* Web Layer
* Application Layer
* Domain Layer
* Infrastructure Data Layer
* Infrastructure IoC Layer

-- Docker

The application can be containerized and run using Docker and Docker Compose.

The project is actively being developed, with additional backend and API functionality planned.
